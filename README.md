# 🌍 AYBIS — Afet Yönetim Bilgi Sistemi

AYBIS (Afet Yönetim Bilgi Sistemi), afet ve özellikle deprem verilerinin kullanıcıya anlaşılır şekilde sunulmasını amaçlayan web tabanlı bir bilgi sistemidir.

## ✨ Özellikler

- 🌐 Çok dilli kullanıcı arayüzü
- 🔐 Kullanıcı giriş sistemi
- 📊 Yönetim paneli ve veri tabloları
- 📈 Grafiklerle veri görselleştirme
- 🗺️ Etkileşimli harita
- 🌍 Gerçek zamanlı deprem verilerinin görüntülenmesi
- 🔎 Veri filtreleme ve tablo işlemleri
- ⚡ Dinamik ve kullanıcı dostu arayüz

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- Leaflet
- DataTables
- SweetAlert
- REST API

## 🗺️ Harita ve Deprem Verileri

Sistem, deprem verilerini harita üzerinde görselleştirerek kullanıcıların deprem bilgilerine daha kolay ulaşmasını sağlar.

Deprem konumları interaktif harita üzerinde gösterilir ve veriler tablo/grafik yapılarıyla desteklenir.

## 🎯 Projenin Amacı

Afet durumlarında kullanılabilecek bilgilerin daha düzenli, anlaşılır ve erişilebilir şekilde sunulmasını sağlamak.

## 📚 Proje

Bu proje, Yönetim Bilişim Sistemleri kapsamında geliştirilmiştir.
